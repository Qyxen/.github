# Qyxen

**Open-source tools for nuclear science and fusion engineering.**

Qyxen develops computational tools, scientific software, and open-source
workflows for nuclear engineering, fusion energy, and scientific computing.

Our goal is to make specialized research tools accessible, reproducible,
and useful to the scientific community.

## Contributing

We welcome contributions, bug reports, and scientific discussions.
Explore our repositories to find a project that interests you.

## Contact

For questions, collaboration, or contributions, open an issue
in the relevant repository.
